# nimiq-collections

Collections used across the Nimiq crates. It currently provides `BitSet`, a compact, serializable set of small
integers.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-collections).
