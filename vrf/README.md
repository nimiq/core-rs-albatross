# nimiq-vrf

A verifiable random function based on VXEdDSA, and the random number generator and discrete distributions that Nimiq
derives from its output.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-vrf).
