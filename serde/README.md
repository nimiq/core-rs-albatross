# nimiq-serde

Serialization helpers for Nimiq on top of [serde](https://serde.rs/) and [postcard](https://docs.rs/postcard): the
`Serialize` and `Deserialize` traits used for Nimiq's binary encoding, fixed-size types and serialized size
helpers.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-serde).
