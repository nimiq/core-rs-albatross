# nimiq-mempool-task

`MempoolTask`, which keeps a `nimiq-mempool` up to date with blockchain events. It can be spawned as its own task or
polled as a stream by the validator.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-mempool-task).
