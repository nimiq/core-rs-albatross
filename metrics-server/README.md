# nimiq-metrics-server

A [Prometheus](https://prometheus.io/) metrics server for the Nimiq node. It exports metrics about the chain,
consensus, mempool, network and tokio tasks.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-metrics-server).
