# nimiq-hash_derive

The `SerializeContent` derive macro, which lets `nimiq-hash` hash a type through its serialized representation.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-hash_derive).
