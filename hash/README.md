# nimiq-hash

The hash functions used in Nimiq behind a common interface: Blake2b, Blake2s, SHA-256 and SHA-512, plus HMAC, PBKDF2 and
Argon2 key derivation.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-hash).
