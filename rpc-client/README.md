# nimiq-rpc-client

A client for the JSON-RPC API of a Nimiq node, along with `nimiq-rpc`, a command-line tool built on it.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-rpc-client).
