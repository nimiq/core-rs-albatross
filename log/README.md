# nimiq-log

Logging helpers for Nimiq based on [`tracing`](https://docs.rs/tracing): the list of Nimiq log targets, filter
helpers and the formatting used by the node.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-log).
