# nimiq-handel

An implementation of [Handel](https://arxiv.org/abs/1906.05132), a scalable protocol for aggregating signatures. Nimiq
validators use it to aggregate their BLS signatures.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-handel).
