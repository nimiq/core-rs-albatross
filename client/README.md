# nimiq-client

The Nimiq node binary, `nimiq-client`. It runs a full, history or light node, and optionally a validator, configured
through a TOML file and command-line options.

See the [repository README](https://github.com/nimiq/core-rs-albatross#readme) for how to configure and run a node.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-client).
