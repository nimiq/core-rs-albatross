# nimiq-network-interface

The network abstraction used by the Nimiq crates: the `Network` trait, gossip topics, request and response messages,
peer information and validator records. `nimiq-network-libp2p` is its implementation.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-network-interface).
