# nimiq-utils

Utilities used across the Nimiq crates, such as CRC, Merkle proofs, value interning, secure key RNGs, tagged signing,
time helpers, streams, and task spawning that works natively and in WebAssembly.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-utils).
