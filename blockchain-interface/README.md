# nimiq-blockchain-interface

Types shared by all blockchain implementations: the `AbstractBlockchain` trait, `ChainInfo`, chain ordering, and the
events, results and errors produced when pushing blocks.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-blockchain-interface).
