# nimiq-validator

The validator of a Nimiq node. It produces micro blocks, runs Tendermint to produce macro blocks, and aggregates the
signatures needed for skip blocks.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-validator).
