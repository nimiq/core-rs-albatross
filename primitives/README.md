# nimiq-primitives

Basic types shared by the Nimiq crates: coins, network IDs, the protocol policy constants, account and transaction
types, validator slots, trie keys and Merkle trees.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-primitives).
