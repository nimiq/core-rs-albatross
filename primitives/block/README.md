# nimiq-block

The block types of Nimiq's Albatross: micro, macro and skip blocks, together with their proofs, equivocation proofs
and the Tendermint justifications of macro blocks.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-block).
