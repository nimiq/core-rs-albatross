# nimiq-account

The accounts of Nimiq and the accounts tree that stores them. It implements basic accounts, vesting contracts, HTLCs
and the staking contract, and how each of them reacts to transactions and inherents.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-account).
