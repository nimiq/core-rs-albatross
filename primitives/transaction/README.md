# nimiq-transaction

Nimiq transactions: their types and signature proofs, transaction data for the different account types, inherents,
historic transactions and history proofs.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-transaction).
