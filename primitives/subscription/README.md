# nimiq-subscription

`Subscription`, a filter that decides which blocks and transactions a subscriber is interested in.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-subscription).
