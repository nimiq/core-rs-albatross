# nimiq-rpc-server

The JSON-RPC server of a Nimiq node. It implements the API defined in `nimiq-rpc-interface`.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-rpc-server).
