# nimiq-key-derivation

Hierarchical deterministic derivation of Ed25519 keys following [SLIP-0010](https://github.com/satoshilabs/slips/blob/master/slip-0010.md),
including derivation paths and conversion to Nimiq keys and addresses.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-key-derivation).
