# nimiq-transaction-builder

`TransactionBuilder`, which builds Nimiq transactions from a sender and a recipient description, together with
`TransactionProofBuilder` for the matching signature proofs.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-transaction-builder).
