# nimiq-wallet

Wallet accounts for Nimiq: single-key wallet accounts, multisig accounts and, with the `store` feature, a wallet store
kept in the database.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-wallet).
