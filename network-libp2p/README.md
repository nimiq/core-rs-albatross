# nimiq-network-libp2p

The implementation of `nimiq-network-interface` based on [libp2p](https://libp2p.io/). It covers peer discovery,
gossipsub, the Kademlia DHT and request-response messaging, on native targets and in the browser via WebAssembly.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-network-libp2p).
