# nimiq-validator-network

The `ValidatorNetwork` trait and its implementation on top of `nimiq-network-interface`, which validators use to find
and message each other.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-validator-network).
