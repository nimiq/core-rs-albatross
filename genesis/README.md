# nimiq-genesis

Network information and genesis data for the Nimiq networks (main, test, dev and unit). The genesis blocks and their
initial accounts are generated at build time from the TOML configurations in `src/genesis`.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-genesis).
