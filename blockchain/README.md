# nimiq-blockchain

The full blockchain of a Nimiq node. It verifies and pushes micro, macro and skip blocks, keeps the chain and history
stores in the database, handles rebranching, produces new blocks for validators and computes the batch rewards.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-blockchain).
