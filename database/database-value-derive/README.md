# nimiq-database-value-derive

The `DbSerializable` derive macro, which implements the `nimiq-database-value` traits for types that can be serialized
with `nimiq-serde`.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-database-value-derive).
