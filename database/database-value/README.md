# nimiq-database-value

The `AsDatabaseBytes`, `FromDatabaseBytes` and `IntoDatabaseValue` traits that convert values to and from the bytes
stored by `nimiq-database`, with implementations for common types.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-database-value).
