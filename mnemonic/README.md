# nimiq-mnemonic

Mnemonic phrases for Nimiq: conversion between entropy and BIP39 mnemonics (and the legacy Nimiq checksum), with
optional key derivation from a mnemonic.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-mnemonic).
