# nimiq-macros

Macros used across the Nimiq crates, for example to create fixed-size byte array types with hex, serialization and
constant-time comparison support.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-macros).
