# nimiq-lib

The library behind `nimiq-client`. It builds a node from its configuration (config file and command line) and wires
together the blockchain, network, consensus, mempool, validator, RPC server and metrics server.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-lib).
