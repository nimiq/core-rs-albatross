# nimiq-rpc-interface

The traits and types that define the JSON-RPC API of a Nimiq node (blockchain, consensus, mempool, network, policy,
validator and wallet). They are shared by `nimiq-rpc-server` and `nimiq-rpc-client`.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-rpc-interface).
