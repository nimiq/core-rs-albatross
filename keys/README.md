# nimiq-keys

Key handling for Nimiq: Ed25519 key pairs, signatures and addresses, ES256 (WebAuthn) public keys and signatures, and
multisig keys.

This crate is part of [Nimiq's Rust implementation](https://github.com/nimiq/core-rs-albatross) of the Albatross
protocol. Its version follows the releases of the Nimiq node.

## Documentation

The API documentation is available on [docs.rs](https://docs.rs/nimiq-keys).
